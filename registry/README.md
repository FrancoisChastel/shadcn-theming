# Registry: themes + extension components

Everything here installs into a shadcn/ui project (Tailwind v4) with
`npx shadcn add <raw-url>`, and is colored entirely through shadcn theme tokens
(`primary`, `destructive`, `chart-*`, `muted-foreground`, `border`), so it
automatically matches any brand theme produced by
[`shadcn-theming`](../README.md) — theme, components, and charts stay one system.

## Themes

Prebuilt brand themes generated by this tool:

```bash
# The IMF flagship example — verified #004C97, real WEO chart palette, 3px radius
npx shadcn@latest add https://raw.githubusercontent.com/FrancoisChastel/shadcn-theming/main/registry/themes/imf-theme.json
```

## Components

### UI extensions

| Item | Description |
| --- | --- |
| `sparkline` | Tiny dependency-free SVG trend line; inherits `text-primary`. |
| `stat-card` | KPI tile: value, trend delta, optional inline sparkline. |

### Scientific charts (seaborn-like)

Built on [**Observable Plot**](https://observablehq.com/plot/) (the D3 team's
grammar-of-graphics library) for recognized, publication-quality marks —
`linearRegressionY` (regression + confidence band), `boxY`, `binX` (density),
and `cell` (heatmap), with built-in interactive tips. Colored through theme
tokens, so they match any brand.

| Item | Seaborn analogue | Description |
| --- | --- | --- |
| `histogram` | `histplot(kde=True)` | Density histogram with an optional Gaussian KDE overlay. |
| `box-plot` | `boxplot` | Grouped Tukey boxes, whiskers, outliers. |
| `scatter-plot` | `regplot` | Scatter with OLS regression line + 95% confidence band. |
| `area-band` | — | Line with confidence/projection band + dashed forecast (IMF WEO fan chart). |
| `correlation-heatmap` | `heatmap(df.corr())` | Diverging correlation matrix (theme-derived scale). |
| `use-plot` | (lib) | React hook: render a Plot figure into a responsive container. |
| `stats` | (lib) | Gaussian KDE + Pearson correlation matrix. |

Each chart pulls in `@observablehq/plot` and the `use-plot` hook automatically.

### Business charts

| Item | Description |
| --- | --- |
| `line-chart` | Multi-series line / time series with a legend. |
| `bar-chart` | Grouped or stacked bars (`stacked` prop). |
| `donut-chart` | Composition donut with legend + center label (d3-shape). |
| `bullet-chart` | KPI vs target (track + actual bar + target tick). |

For a full prop reference and install-and-use guidance, see the
[`shadcn-theming-components` skill](../skills/shadcn-theming-components/SKILL.md).

Install (dependencies resolve automatically — `plot-frame` and `stats` come with
any chart):

```bash
npx shadcn@latest add https://raw.githubusercontent.com/FrancoisChastel/shadcn-theming/main/registry/scatter-plot.json
npx shadcn@latest add https://raw.githubusercontent.com/FrancoisChastel/shadcn-theming/main/registry/histogram.json
npx shadcn@latest add https://raw.githubusercontent.com/FrancoisChastel/shadcn-theming/main/registry/correlation-heatmap.json
```

## Usage

```tsx
import { StatCard } from "@/components/ui/stat-card"
import { Histogram } from "@/components/ui/histogram"
import { ScatterPlot } from "@/components/ui/scatter-plot"
import { BoxPlot } from "@/components/ui/box-plot"
import { AreaBand } from "@/components/ui/area-band"
import { CorrelationHeatmap } from "@/components/ui/correlation-heatmap"

<StatCard label="World GDP growth" value="3.2%" delta={0.1} data={series} />
<Histogram data={growthRates} kde title="Distribution of country growth" />
<ScatterPlot data={points} regression band title="Phillips curve" />
<BoxPlot groups={[{ label: "Advanced", values: a }, { label: "Emerging", values: b }]} />
<AreaBand data={[{ x: 2024, y: 3.2 }, { x: 2025, y: 3.1, lower: 2.8, upper: 3.4, forecast: true }]} />
<CorrelationHeatmap labels={["GDP", "Inflation", "Debt"]} columns={[gdp, cpi, debt]} />
```

See the rendered result in [`../demo/imf-showcase.html`](../demo/imf-showcase.html).

## Layout

```
registry/
  components/lib/stats.ts    # shared statistics (registry:lib)
  components/ui/*.tsx         # component sources (edit these)
  themes/*.json              # generated brand themes
  <name>.json                # generated, installable registry items
  registry.json              # generated index
```

Regenerate the JSON after editing a source:

```bash
npm run registry:build
```

## Adding a component

1. Add `registry/components/ui/<name>.tsx` (keep it token-driven — use
   `text-primary`, `fill-chart-1`, `stroke-border`, etc.).
2. Register it in `scripts/build-registry.mjs` (`ITEMS`), listing `type`,
   `target`, and any `registryDependencies` (bare shadcn names resolve
   automatically; cross-repo items use their raw URL).
3. Run `npm run registry:build` and commit the generated JSON.
